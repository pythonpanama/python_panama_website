Gemma 4 en tu computadora

Un modelo abierto de Google, con un solo comando

Recurso de MLH · «How to Run Google's Gemma 4 Locally with Ollama» · David (purpledoubled) en DEV

⏱ 0:00 – 0:01 Gemma 4 es la familia de modelos abiertos de Google y además es el reto de socio de nuestro Hack Day. Esta charla es para correrlo en local; al final se explica por qué eso no basta para el reto Gemma.

Instalar y correr

# 1. instala Ollama desde ollama.com y luego:
ollama run gemma4        # por defecto baja e4b

# o elige el tamaño
ollama run gemma4:e2b
ollama run gemma4:e4b
ollama run gemma4:26b
ollama run gemma4:31b

La primera vez descarga el modelo. Después funciona sin internet.

⏱ 0:01 – 0:02 Comandos tal cual del artículo. ollama run abre un chat en la terminal; para salir, /bye. Si solo quieres descargar sin abrir el chat: ollama pull.

Descarga según ollama.com/library/gemma4 (26 oct 2026); memoria según el artículo. Hoy también existe gemma4:12b, que el artículo no compara.
⏱ 0:02 – 0:04 «E» es «efectivo»: modelos pensados para celular y laptop. El 26B es Mixture of Experts: de 128 expertos usa unos 4B parámetros por token, por eso es rápido. Pero Google aclara que hay que cargar los 26B completos: con una GPU de 8 GB, el resto se queda en RAM y va más lento. El artículo lo vende como «calidad de 26B con 8 GB de VRAM»; matízalo. Para el 31B, el artículo habla de una RTX 4090 o una Mac de 32 GB o más.

Descárgalo en casa, no en el salón.

El más pequeño pesa varios GB. Veinte personas bajándolo a la vez tumban el wifi.

⏱ 0:04 – 0:05 Recordatorio práctico para el sábado 31: quien quiera usar Gemma en local trae el modelo descargado desde el viernes 30. Si no tiene, que use la Gemini API, que no descarga nada.

Qué trae de nuevo frente a Gemma 3

Más libre

Licencia Apache 2.0

Uso comercial, ajuste fino y redistribución. Gemma 3 tenía términos propios más restrictivos.

Más capaz
  • Llamadas a funciones nativas, en formato OpenAI.
  • Modo de pensamiento configurable.
  • Imagen en todos; audio en los pequeños.
  • Contexto de 128K (pequeños) a 256K.
⏱ 0:05 – 0:06 La licencia importa para el reto open-source: hay que enlazarla en el README. Las llamadas a funciones son lo que permite usar Gemma dentro de un agente: el modelo devuelve «llama a buscar_clima con ciudad=Panamá» en JSON y tu programa lo ejecuta. Eso conecta con las charlas 07 y 08.

Desde tu código

import requests

r = requests.post(
    "http://localhost:11434/api/generate",
    json={"model": "gemma4:e2b", "prompt": "Hola", "stream": False},
    timeout=120,  # la primera llamada carga el modelo
)
print(r.json()["response"])

Es el mismo ejemplo de ollama_ejemplo.py, solo que con gemma4:e2b. Para el formato OpenAI, mira la charla anterior.

⏱ 0:06 – 0:07 El ejemplo del repo todavía dice MODELO = "gemma3"; basta cambiar esa línea. El timeout de 120 segundos no es exageración: la primera petición carga el modelo en memoria y puede tardar bastante en una laptop.
