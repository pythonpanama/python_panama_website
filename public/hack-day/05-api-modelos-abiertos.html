Qué es «open-weight»

La definición

Los pesos se pueden descargar

Puedes bajar el modelo y ejecutarlo según los términos de quien lo publica.

No significa que todo sea open source: los datos y el entrenamiento pueden seguir cerrados.

Lo que gana el desarrollador
  • Transparencia: la comunidad lo audita.
  • Ajuste fino con tus propios datos.
  • Costo: lo alojas tú o eliges proveedor.
  • Sin amarre: cambias de proveedor sin reescribir.
Para el reto open-source del Hack Day: nombra el modelo y enlaza su licencia en el README.
⏱ 0:01 – 0:02 La definición de la izquierda es la del handbook de MLH, más precisa que la del artículo. Las cuatro ventajas son las del artículo; el artículo no da cifras de costo, así que no prometas «una fracción del precio» sin números.

Dos caminos para usarlo

Local

Ollama o vLLM

El modelo corre en tu computadora. Funciona sin internet y tus datos no salen.

Pide memoria y, para modelos grandes, una GPU.

Por API

Un proveedor lo aloja

No necesitas hardware: mandas la petición y pagas por token.

Necesitas una clave y aceptar que tus datos viajan.

La buena noticia: casi todos hablan el mismo formato, el de /v1/chat/completions.

Para un modelo pequeño como Gemma 4 E2B no es así: corre en una laptop. Eso es la siguiente charla.

La forma de toda llamada

PasoQué esEjemplo
1. AutenticaciónClave en la cabeceraAuthorization: Bearer …
2. EndpointLa dirección del servicio/v1/chat/completions
3. CuerpoModelo, mensajes y parámetrosmodel, messages, temperature
4. RespuestaEl texto, y los límites de usochoices[0].message.content

Los mensajes tienen rol: system (cómo se comporta), user (lo que pides) y assistant (lo que respondió antes).

⏱ 0:03 – 0:04 Los cuatro pasos son los del artículo. Insiste en el paso 4: la API puede responder con error por límite de peticiones o de tokens, y el programa tiene que manejarlo en vez de romperse.

Primera llamada, en tu máquina

# Ollama ya habla el formato OpenAI en el puerto 11434
ollama pull gemma4:e2b

curl http://localhost:11434/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "gemma4:e2b",
       "messages": [{"role": "user", "content": "¿Qué es Hacktoberfest?"}]}'

En local no hace falta clave: no sale nada de tu computadora.

⏱ 0:04 – 0:05 Si hay tiempo, hazlo en vivo con el modelo ya descargado (la descarga pesa varios GB: nunca en el wifi del salón). Base y endpoints tomados de la documentación de compatibilidad OpenAI de Ollama, consultada el 26 oct.

Cambiar de proveedor es cambiar tres datos

import os
from openai import OpenAI
cliente = OpenAI(base_url=os.getenv("LLM_BASE_URL", "http://localhost:11434/v1/"),
                 api_key=os.getenv("LLM_API_KEY", "ollama"))  # Ollama la ignora
respuesta = cliente.chat.completions.create(
    model=os.getenv("LLM_MODELO", "gemma4:e2b"),
    messages=[{"role": "user", "content": "Dame una idea de proyecto."}])
print(respuesta.choices[0].message.content)

Dirección, clave y modelo salen del entorno: el código no cambia.

⏱ 0:05 – 0:06 Esto es lo que el artículo llama «sin amarre al proveedor», demostrado. El cliente oficial de OpenAI sirve para cualquier servicio compatible. Se instala con pip install openai. La clave real va en un archivo .env que está en .gitignore.

Los parámetros que importan

ParámetroQué controlaValor de partida
temperatureCuánto se arriesga al elegir palabras0.2 para código · 0.8 para ideas
max_tokensLargo máximo de la respuesta, y del costoLo que quepa en tu pantalla
top_pSolo considera las palabras más probables0.9
frequency_penalty · presence_penaltyCastigan que se repitaSúbelos si repite frases

Cambia uno a la vez y compara: así aprendes qué hace cada uno.

⏱ 0:06 – 0:07 Los valores de temperatura y top_p son los del artículo. Con max_tokens pasa algo que confunde: si la respuesta sale cortada a media frase, casi siempre es porque se llegó al límite, no un error del modelo.

Respuestas en streaming

flujo = cliente.chat.completions.create(
    model="gemma4:e2b",
    messages=[{"role": "user", "content": "Cuenta hasta diez."}],
    stream=True,
)
for trozo in flujo:
    print(trozo.choices[0].delta.content or "", end="", flush=True)

El texto llega a pedazos, como en un chat. Por debajo son eventos data: … que terminan en data: [DONE].

⏱ 0:07 – 0:08 El artículo lee los eventos a mano con requests e imprime el JSON crudo. Con el cliente de OpenAI ya llega parseado: delta.content es el pedazo de texto nuevo. Para una demo, streaming hace que el modelo se sienta mucho más rápido.
Antes de copiar código

Tres cuidados

  • Siempre https:// con un proveedor. El ejemplo del artículo usa http://: la clave viajaría sin cifrar.
  • La clave nunca en el código ni en el repo: va en .env, y .env va en .gitignore.
  • Reto Gemma: exige Gemma por la Gemini API. Para ese reto usa la plantilla de la Gemini API, no Ollama.
El artículo es de un proveedor y promociona su servicio. El patrón sirve; la elección de proveedor es tuya.
⏱ 0:08 – 0:09 Lo de http es real (revisado el 26 oct): el endpoint de ejemplo es http://www.novapai.ai/v1/chat/completions. Úsalo como ejemplo de qué revisar antes de pegar código de internet. El reto Best Open-Source AI Project sí acepta Ollama local. El reto Gemma no: el criterio de MLH pide «a Gemma model through the Gemini API».
