⏱ 0:02 – 0:03 El gancho: los chatbots responden con lo que saben; un agente de navegador va a buscarlo. Stagehand es la pieza que traduce instrucciones en español o inglés a clics y lecturas reales en una página web.

Qué es Stagehand

El proyecto

SDK para agentes de navegador

Extrae datos e interactúa con cualquier sitio web usando lenguaje natural cuando conviene y código cuando hace falta precisión.

Lo mantiene Browserbase. Unas 25 800 estrellas en GitHub.

Lo abierto

Licencia MIT

SDK en TypeScript, Python y Go, en un solo repositorio.

Corre con Chrome en tu máquina o en la nube de Browserbase.

Fuente: github.com/browserbase/stagehand, consultado el 26 oct 2026.
⏱ 0:03 – 0:04 La idea clave: Playwright y Selenium hacen clic en un selector exacto, que se rompe cuando la página cambia. Stagehand deja que un modelo de lenguaje encuentre el elemento a partir de una descripción, y te devuelve el selector para que lo uses con código normal si quieres.

Las primitivas

PrimitivaQué haceEjemplo
actEjecuta una acción descrita en lenguaje natural«haz clic en Iniciar sesión»
observeEncuentra elementos y devuelve su selector real«busca el campo de correo»
extractSaca datos con una forma definida por un esquema«todas las facturas de la tabla»
agentEncadena pasos solo, para tareas de varias páginas«compara precios en tres tiendas»

Un asistente se arma combinándolas: el modelo decide el paso, Stagehand lo ejecuta en el navegador.

⏱ 0:04 – 0:05 act, observe y extract salen del README. agent es la primitiva para tareas de varios pasos; revisa su API en la documentación antes de mostrar código de ella, porque el README no trae ejemplo.

Actuar y observar

pnpm add @browserbasehq/stagehand zod   # TypeScript
pip install stagehand                   # Python
// una acción en lenguaje natural
await stagehand.act("click the sign in button");

// o pedir el selector y seguir con código
const { data: email } = await stagehand.observe("find the email input");
await page.locator(email[0].selector).fill(process.env.APP_EMAIL!);
⏱ 0:05 – 0:06 Ejemplos tal cual del README. El segundo es el patrón importante: observe usa el modelo una vez para encontrar el elemento y después todo es Playwright normal, más rápido y más barato. Fíjate en que la clave de la cuenta sale de una variable de entorno, nunca escrita en el código: es lo mismo que se enseña en la mesa 1 con las claves.

Extraer datos con forma

const { data } = await stagehand.extract(
  "extract every invoice in the table",
  z.object({
    invoices: z.array(z.object({
      number: z.string(), amount: z.number(), paid: z.boolean(),
    })),
  }),
);

El esquema (Zod en TypeScript, Pydantic en Python) obliga al modelo a devolver datos que tu programa puede usar, no un párrafo.

⏱ 0:06 – 0:07 Esta es la diferencia entre «el modelo me contó» y «tengo una lista con número, monto y si está pagada». Para un asistente, extract es lo que convierte una página en una respuesta verificable.

Dónde corre el navegador

Local

Tu Chrome

Necesitas Chrome instalado. Las cookies quedan en una carpeta y se conservan entre ejecuciones.

Gratis y suficiente para aprender y para contribuir.

Nube

Browserbase

Servicio de pago con clave de API: navegadores en la nube, caché, proxies, sesiones grabadas y un gateway que elige el modelo.

El SDK es abierto; el modelo de lenguaje que uses es aparte. Revisa su licencia y adónde mandas tus datos.

Track 2

Contribuir a Stagehand

  • Lee CONTRIBUTING.md: «los arreglos de bugs y las mejoras pequeñas son la mejor forma de empezar».
  • Para preparar el repo: just install, just generate y just build.
  • Cambios grandes: pregunta primero al equipo en su Discord.
  • Sin programar también aportas: documentación y errores bien reportados.
  • Ya no cuenta PR: vale que el cambio sirva.
⏱ 0:08 – 0:09 Es un proyecto grande y con empresa detrás: un PR puede tardar en recibir respuesta. Igual que en la charla 3, el éxito de hoy es enviarlo bien hecho. Comprobado el 26 oct 2026: el repositorio no tiene issues abiertos con «good first issue»; busca un bug pequeño o documentación confusa.
