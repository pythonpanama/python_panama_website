Gemma 4 desde la terminal

La CLI oficial de la Gemini API

Google AI Studio · gemini-api · beta, versión 0.4.4 del 23 oct 2026

⏱ 0:00 – 0:01 En la charla 06 vimos que Gemma con Ollama no sirve para el reto Gemma, porque el reto exige la Gemini API. Esta herramienta es el camino más corto para cumplirlo: un comando en la terminal.

Una línea en la terminal y ya usas Gemma por la Gemini API.

Es lo que pide el reto Best Use of Gemma 4, sin escribir un programa.

⏱ 0:01 – 0:02 Criterio de MLH: «Confirm that the winning project actually uses a Gemma model through the Gemini API». Con esta CLI, un script de shell o un agente pueden usar Gemma por la API oficial.

Qué es

La herramienta

Un solo binario

Sin dependencias, para macOS, Linux y Windows. Escrito en Go, licencia Apache 2.0.

No guarda estado: cada comando es independiente.

Para quién
  • Scripts de shell y CI.
  • Agentes con terminal: Claude Code, Codex, Antigravity, OpenClaw o Hermes.
  • Para una app en producción, Google recomienda los SDK.
No es «Gemini CLI», el agente de terminal. Esta se llama gemini-api y solo llama a la API.
⏱ 0:02 – 0:03 La confusión de nombres es segura: Gemini CLI es un agente que conversa contigo en la terminal; gemini-api es una herramienta para que tú o tu agente llamen a la API. Los SDK son google-genai en Python, que es lo que usa la plantilla de material-del-dia/codigo/ia-codigo-abierto/gemma-api-ejemplo/.

Instalar y poner la clave

# macOS y Linux
URL=https://raw.githubusercontent.com/google-gemini/gemini-api-cli/main/scripts
curl -fsSL "$URL/install.sh" | bash

# la clave sale de Google AI Studio
gemini-api configure --interactive   # la guarda en el llavero del sistema
gemini-api whoami                    # comprueba de dónde la toma

En Windows, el instalador es scripts/install.ps1 del mismo repositorio. También sirve la variable GEMINI_API_KEY. La clave nunca va en el repo.

⏱ 0:03 – 0:04 configure guarda la clave en el llavero de macOS, Linux o Windows: es más seguro que dejarla en un archivo. Para sacar la clave, el QR aistudio-clave.png de las tarjetas de mesa. Igual que con Hermes: antes de pegar un instalador «| bash» o «| iex», ábrelo y léelo. También hay binarios en GitHub Releases y go install.

Primera llamada con Gemma

gemini-api models                 # el grupo «Gemma» trae los dos modelos

# --dry-run arma la petición sin enviarla ni mostrar la clave
gemini-api generate "¿Qué es Hacktoberfest?" -m gemma-4-26b-a4b-it --dry-run

gemini-api generate "¿Qué es Hacktoberfest?" -m gemma-4-26b-a4b-it
gemini-api generate "Resume este issue" -m gemma-4-31b-it

Ojo: sin -m usa gemini-3.8-flash, que no es Gemma.

⏱ 0:04 – 0:05 Esta es la diapositiva más importante. El modelo por defecto es Gemini, no Gemma: un equipo que olvide -m no estaría usando Gemma y no calificaría al reto. Los dos nombres salen del catálogo del código fuente de la CLI (26 oct). Son los mismos de la plantilla de Python (gemma-4-26b-a4b-it). [PENDIENTE: probarlo con una clave real antes del sábado.]

⏱ 0:05 – 0:06 Úsalo para que los equipos imaginen proyectos: transcribir una charla y que Gemma la resuma, analizar un PDF de un trámite, etc. Pero recuérdales que si el corazón del proyecto es una imagen generada por Gemini, eso no es «uso de Gemma». --output-format json y --jq dan salida estructurada para scripts.

Dásela a tu agente

# en AGENTS.md, CLAUDE.md o las instrucciones de tu agente
You have access to gemini-api through the shell.
Use it to call Gemini models, generate or edit media,
analyze files, or launch managed agents.
1. Inspect --help or --usage to choose a command,
   and --schema when building a --body JSON payload.
2. Preview API calls with --dry-run.

Así cualquier agente con terminal usa Gemma. Idea de proyecto: un skill que envuelva gemini-api -m gemma-4-… para una tarea concreta.

Antes de entregar

  • Cada llamada lleva -m gemma-4-26b-a4b-it o gemma-4-31b-it.
  • El README nombra el modelo y la demo muestra el comando.
  • La clave queda fuera del repo: llavero o .env en .gitignore.
  • Es beta: anota la versión que usaste (gemini-api version).
  • No acepta PR: si algo falla, abre un issue.
⏱ 0:07 – 0:08 El handbook pide «nombrar el modelo en el README y mostrar la integración en el código o la demo». El README de la CLI advierte que puede haber cambios incompatibles entre versiones y recomienda fijar una. No sirve para contribuir con código: «We are not accepting open source contributions (pull requests) at this time». Los issues sí son bienvenidos.
